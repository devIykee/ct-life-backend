CT Life REST API (1.0.0-rc1)

Download OpenAPI specification:

URL: https://github.com/devIykee/ct-life-backend License: MIT

REST v1 for the CT Life backend. Every endpoint is keyed by x-phase (1-6) and lists the error codes it can return, the auth policy, the idempotency contract, the headers it reads, and at least one example response.

The contract is the source of truth; the Unity client consumes it. Breaking changes bump the major version; additive changes bump the minor version and are recorded in contract/CHANGELOG.md.

All money is bigint cents (field names end in Cents) or string base units (token amounts). Times are ISO-8601 UTC for REST, epoch milliseconds for realtime. The week runs Mon 00:00 to Sun 23:59:59 UTC.

auth

Sign In With Solana, JWT, refresh, JWKS. Phases 1+.

Issue a SIWS challenge (nonce + SIWS message fields).

Returns a single-use nonce (5 min) and the SIWS message fields. The client builds sign_in_payload for the wallet, signs it, and posts the result to POST /auth/verify. Anonymous.
